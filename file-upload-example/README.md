
# Alkuun

1. Asenna riippuvuudet suorittamalla file-upload-example -polussa `deno install` komento
2. Käynnistä kehityspalvelin `deno task dev`
3. Avaa terminaaliin tulostuva osoite selaimessa ja kokeile lähettää **kuva**. Tiedosto tallentuu ./uploads kansioon.

HUOM. Koodista puuttuu virheiden käsittely ja datan validointi
